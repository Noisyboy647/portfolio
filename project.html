Welkom op mijn projectenpagina! Op dit moment staat hier nog geen eindresultaat, omdat ik nog niet effectief begonnen ben met het bouwen van deze portfolio-website. Het maken van dit portfolio is namelijk een groot project waar we doorheen het hele schooljaar stap voor stap aan gaan werken. De komende tijd ga ik deze website helemaal zelf vanaf de basis opbouwen en vormgeven. Om dit te realiseren, gebruik ik Visual Studio Code als mijn vaste code-editor. De website zelf zal ik gaan schrijven met behulp van de volgende programmeertalen: • HTML: Voor het opbouwen van de basisstructuur en de inhoud van de pagina's. • CSS: Voor de volledige visuele opmaak, zoals het toepassen van mijn eigen huisstijl, de lay-out en de kleuren. • JavaScript / Java: Voor het toevoegen van extra functionaliteiten en interactieve elementen op de website. Omdat we hier het hele jaar door aan werken, zal deze website (en deze projectenpagina) de komende maanden steeds verder groeien en verbeteren. Kom dus zeker later nog eens terug om mijn voortgang en toekomstige projecten te bekijken!
